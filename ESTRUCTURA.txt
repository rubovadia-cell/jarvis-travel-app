🎯 FLUJO DE DATOS:

1️⃣  Usuario abre app web (browser)
    ↓
    src/index.html (React-like vanilla JS)
    
2️⃣  Usuario ingresa origen, destino, fechas
    ↓
    JavaScript hace POST a /api/quote
    
3️⃣  Backend (Express) recibe solicitud
    ↓
    server/index.js
    
4️⃣  Backend obtiene datos reales de APIs
    ├── Vuelos (Skyscanner mock)
    ├── Hoteles (Booking mock)
    └── Transporte (Google Maps mock)
    
5️⃣  Backend envía a Claude para análisis
    ↓
    Claude Opus 4.6 analiza datos
    
6️⃣  Claude retorna 3 paquetes optimizados
    ├── Económica
    ├── Recomendada
    └── Premium
    
7️⃣  Backend retorna JSON al frontend
    ↓
    src/index.html renderiza resultados
    
8️⃣  Usuario ve paquetes interactivos

📱 PWA (Progressive Web App):

✓ Instalar como app en móvil/desktop
✓ Funciona offline (Service Worker)
✓ Carga rápida (cache)
✓ Notificaciones (futuro)

Instalar:
  Chrome:  Ícono en barra de direcciones → "Instalar"
  Safari:  Compartir → "Agregar a pantalla de inicio"
  Android: Menú → "Instalar app"
