│                         ⚡ EMPEZAR EN 2 MINUTOS                            │
└────────────────────────────────────────────────────────────────────────────┘

1. OBTENER API KEY
   Ir a: https://console.anthropic.com
   Copiar: sk-ant-...

2. CONFIGURAR
   cp .env.example .env
   Editar .env: ANTHROPIC_API_KEY=sk-ant-...

3. INSTALAR
   npm install

4. EJECUTAR
   npm run dev

5. ABRIR
   http://localhost:3000

OPCIÓN 1: Railway.app (⭐ MÁS FÁCIL)
  • Conectar GitHub
  • Railway detecta automáticamente Node.js
  • Agregar ANTHROPIC_API_KEY
  • Deploy automático en push
  • Gratis con crédito: $5 USD/mes

OPCIÓN 2: Vercel (Frontend)
  • Frontend en Vercel
  • Backend en Railway/Heroku
  • Deploy desde GitHub
  • Gratis

OPCIÓN 3: Docker
  • docker build -t jarvis-travel .
  • docker run -e ANTHROPIC_API_KEY=... -p 3000:3000 jarvis-travel
  • Push a Docker Hub
  • Deploy a cualquier cloud

VER: DEPLOY.md para instrucciones detalladas
